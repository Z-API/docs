## Conceituação

Método utilizado para deletar uma instância vinculada à sua conta. Para deletar várias de uma vez, use [Deletando instâncias em lote](/partner/delete-instances).

<Warning>
Para utilizar os endpoints de Partner, informe o Token de Parceiro no campo **Authorization**, no formato: `Bearer <Partner-Token>`

Não é necessário enviar o **Client-Token** nessas requisições.
</Warning>

<Warning>
A exclusão é definitiva e não pode ser desfeita.
</Warning>

---

## Regras de elegibilidade

Uma instância só é deletada quando atende a **todas** as condições abaixo:

- Está **desconectada** do WhatsApp e do celular.
- Está com status de pagamento **pendente**, **trial** ou **cancelado**. Instâncias pagas, com boleto pendente, em processo de cancelamento, em retentativa de pagamento ou sem status de pagamento definido não são elegíveis.
- Se estiver **pendente**, não tem assinatura pendente. Cancele a assinatura antes de deletar a instância.

Instâncias canceladas podem ser deletadas assim que entram nesse status, sem carência após o cancelamento.

## Response

### 204

A instância foi deletada. A resposta não tem corpo.

### 403

A instância não atende às regras de elegibilidade. O campo `type` identifica a regra que bloqueou a exclusão e o campo `message` descreve o motivo.

```json
{
  "type": "INSTANCE_HAS_ACTIVE_SUBSCRIPTION",
  "message": "Cannot delete instance because it has a pending subscription. Cancel the subscription first"
}
```

Motivos possíveis:

| type | message | Quando acontece |
| --- | --- | --- |
| `INSTANCE_STILL_CONNECTED` | `Cannot delete instance because it is still connected to WhatsApp or phone` | A instância ainda está conectada ao WhatsApp ou ao celular. Desconecte antes de deletar. |
| `INSTANCE_PAYMENT_STATUS_MISSING` | `Cannot delete instance because payment status is unknown` | A instância não tem status de pagamento definido. |
| `INSTANCE_NOT_ELIGIBLE` | `Cannot delete instance because it is still active` | O status de pagamento não é pendente, trial nem cancelado (por exemplo: paga, boleto pendente, em processo de cancelamento ou em retentativa de pagamento). |
| `INSTANCE_HAS_ACTIVE_SUBSCRIPTION` | `Cannot delete instance because it has a pending subscription. Cancel the subscription first` | A instância está pendente e tem assinatura pendente. Cancele a assinatura antes de deletar. |

### 401

O header **Authorization** não foi enviado ou o Token de Parceiro é inválido.

```json
{
  "message": "Authorization token is empty"
}
```

### 404

Não existe instância para o par `instanceId` e `token` informado.

```json
{
  "message": "Instance not found"
}
```

### 405

Neste caso certifique que esteja enviando corretamente a especificação do método, ou seja verifique se você enviou o DELETE conforme especificado no início deste tópico.

### 415

Caso você receba um erro 415, certifique de adicionar na headers da requisição o "Content-Type" do objeto que você está enviando, em sua grande maioria "application/json".
