## Overview

Method used to delete an instance linked to your account. To delete several at once, use [Deleting instances in bulk](/en/partner/delete-instances).

<Warning>
To use Partner endpoints, provide the Partner Token in the **Authorization** field using the following format: `Bearer <Partner-Token>`

It is not necessary to send the **Client-Token** in these requests.
</Warning>

<Warning>
Deletion is permanent and cannot be undone.
</Warning>

---

## Eligibility rules

An instance is only deleted when it meets **all** of the conditions below:

- It is **disconnected** from WhatsApp and from the phone.
- Its payment status is **pending**, **trial**, or **canceled**. Paid instances, ones with a pending bank slip, ones in the cancellation process, ones in payment retry, or ones without a defined payment status are not eligible.
- If it is **pending**, it has no pending subscription. Cancel the subscription before deleting the instance.

Canceled instances can be deleted as soon as they enter that status, with no grace period after cancellation.

## Response

### 204

The instance was deleted. The response has no body.

### 403

The instance does not meet the eligibility rules. The `type` field identifies the rule that blocked the deletion and the `message` field describes the reason.

```json
{
  "type": "INSTANCE_HAS_ACTIVE_SUBSCRIPTION",
  "message": "Cannot delete instance because it has a pending subscription. Cancel the subscription first"
}
```

Possible reasons:

| type | message | When it happens |
| --- | --- | --- |
| `INSTANCE_STILL_CONNECTED` | `Cannot delete instance because it is still connected to WhatsApp or phone` | The instance is still connected to WhatsApp or to the phone. Disconnect it before deleting. |
| `INSTANCE_PAYMENT_STATUS_MISSING` | `Cannot delete instance because payment status is unknown` | The instance has no defined payment status. |
| `INSTANCE_NOT_ELIGIBLE` | `Cannot delete instance because it is still active` | The payment status is not pending, trial, or canceled (for example: paid, pending bank slip, in the cancellation process, or in payment retry). |
| `INSTANCE_HAS_ACTIVE_SUBSCRIPTION` | `Cannot delete instance because it has a pending subscription. Cancel the subscription first` | The instance is pending and has a pending subscription. Cancel the subscription before deleting. |

### 401

The **Authorization** header was not sent or the Partner Token is invalid.

```json
{
  "message": "Authorization token is empty"
}
```

### 404

No instance exists for the given `instanceId` and `token` pair.

```json
{
  "message": "Instance not found"
}
```

### 405

Make sure you are correctly sending the method specification, that is, verify that you sent DELETE as specified at the beginning of this topic.

### 415

If you receive a 415 error, make sure to add the "Content-Type" header to your request, which in most cases is "application/json".
